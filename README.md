# Ceia que Vende

A página estática usa o projeto Vercel existente e o domínio natal-lucrativo-br.vercel.app. O objeto CONFIG no rodapé de index.html concentra os links da Cakto e o Pixel. Complete os campos de suporte, responsável e data nos arquivos HTML antes de ativar a venda. Os order bumps e o upsell são configurados na Cakto.

Instale as dependências com `npm install`. Use `npm run dev` para desenvolvimento e `npm run build` para gerar `dist/`. O v0 deve importar a branch `main` e iniciar `npm run dev`. As imagens em `public/img/` mantêm as URLs `/img/` da página publicada.
